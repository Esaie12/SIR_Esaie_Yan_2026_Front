Documentation de l’application CRM

🎯 Présentation du projet

Cette application est un CRM (Customer Relationship Management) permettant de gérer :

  • Les clients
  • Les groupes de clients
  • Les messages envoyés

Elle est développée avec Angular et une API REST.

⚙️ Fonctionnalités
  • Création / modification / suppression de clients
  • Gestion de groupes
  • Assignation de clients à des groupes
  • Envoi de messages individuels ou groupés
  • Dashboard statistique
  • Génération de données de test (faker.js)
🚀 Utilisation
  1. Se connecter à l’application
  2. Accéder au dashboard
  3. Créer des clients et groupes
  4. Envoyer des messages

Les données peuvent être générées automatiquement pour tester le système.

🎲 Génération de données

Le bouton "Générer Data" permet de créer automatiquement :

  • 4 à 8 clients aléatoires
  • 2 à 5 groupes
  • 4 à 8 messages
  • Relations clients ↔ groupes

⚠️ Les données sont fictives et générées avec Faker.js
